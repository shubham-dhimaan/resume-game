# Deploying Your Interactive Resume Game

This project is built with **Vite + React + Tailwind CSS**. It can be deployed in under 2 minutes to any of the free hosting platforms below.

---

### Option 1: Netlify (Fastest - 1 Minute, Drag & Drop or CLI)

#### Method A: Drag & Drop (No git needed)
1. In your terminal, run:
   ```bash
   npm run build
   ```
2. Log in to [app.netlify.com](https://app.netlify.com).
3. Drag the **`dist`** folder directly into the Netlify "Sites" area.
4. Your site is instantly live with an SSL URL to send to Wispr Flow!

#### Method B: Netlify CLI
```bash
npx netlify-cli deploy --prod --dir=dist
```

---

### Option 2: Vercel (Fast & Reliable)
1. Run in terminal:
   ```bash
   npx vercel
   ```
2. Select default options (`dist` as output directory).

---

### Option 3: GitHub Pages
1. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "feat: complete interactive resume game for Wispr Flow hiring challenge"
   ```
2. Create a repo on GitHub and push.
3. Install `gh-pages` or enable GitHub Actions static deployment from the `dist` folder.
