# Shubham Dhiman — Interactive Resume & Game

> An interactive career portfolio and milestone game built for the Wispr Flow hiring challenge.

A playable journey through psychology foundations, pre-training pipelines at Amazon Nova AGI, and frontier reasoning at Turing.

## Tech Stack
- React 19 + TypeScript
- Vite 8 + Tailwind CSS 4
- HTML5 Canvas & Web Audio API
- Canvas Confetti

## Quick Start
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

## GitHub Pages Deployment
This repository is configured with GitHub Actions to automatically build and deploy to GitHub Pages on every push to `main`.
